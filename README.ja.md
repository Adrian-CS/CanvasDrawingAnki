# Kanji Drawing Canvas

> [English](README.md) · [Español](README.es.md) でもご覧いただけます

[Anki](https://apps.ankiweb.net/) 用アドオンです。任意のノートタイプに手書き用の
描画キャンバスを追加し、漢字・ハングルなどの文字をフラッシュカードの復習中に
直接書いて練習できます。デスクトップと**モバイル**の両方で動作します。

---

## 機能

- **独立したキャンバスブロック**をカード内容の下に追加します。既存のテンプレートの
  レイアウトを崩しません。
- **練習用グリッド**: 田字格（4分割）、米字格（4分割＋対角線）、またはグリッドなし。
- 一画ずつ**元に戻す**ボタンと**クリア**ボタン。
- **画数カウンター** — 漢字の画数確認に便利です。
- **筆画の照合**（任意） — 書いた字を、そのカードの文字と照合します。形・位置・
  筆順・書く方向を、書きながら、または書き終えてから判定します。単語が入って
  いるフィールドなら1文字につき1つキャンバスが並びます。モバイルでも動作します。
- **モバイル対応**（AnkiDroid / AnkiMobile）。HTML5 Canvas + Pointer Events を
  使用しているため、モバイル側にアドオンは不要です。
- **UI言語の自動検出**: 英語・スペイン語・日本語から、デバイスのロケールに合わせて
  自動的に選択されます。
- 非破壊的: キャンバスはいつでも同じダイアログからテンプレートに対して削除できます。

## インストール

### AnkiWeb から *（推奨）*

1. Anki で **ツール → アドオン → アドオンを取得** を開きます。
2. アドオンコードを入力します *(AnkiWeb 審査後に公開予定)*。
3. Anki を再起動します。

### 手動インストール

1. このリポジトリをダウンロードまたはクローンします。
2. `kanjiDrawingAnki` フォルダを Anki のアドオンフォルダにコピーします
   （`ツール → アドオン → アドオンフォルダを開く`）。
3. Anki を再起動します。

---

## 使い方

1. **ツール → 描画キャンバス…** を開きます。
2. ドロップダウンから変更したい**ノートタイプ**を選択します。
3. リストから**テンプレート**（通常は *Card 1*）を選択し、**キャンバスを追加**を
   クリックします。
4. 通常通り学習します — カードの表面の下部にキャンバスが表示されます。

**推奨する学習フロー:**

```
表面: 意味・読みを確認  →  文字を書く  →  カードをめくる  →  答えと比較
```

**キャンバスを削除する**には: ダイアログを開き、同じテンプレートを選択して
**キャンバスを削除**をクリックします。

## 正しい字が書けているかを確認する

目視で見比べる代わりに、そのカードの文字と書いた字をキャンバスに照合させる
こともできます。

1. **ツール → 描画キャンバス…** で、**キャンバスを追加**を押す前に、
   **筆画を照合するフィールド**でその文字が入っているフィールド
   （`Kanji`、`漢字`、`Expression` など）を選びます。候補が自動で選択されます。
2. **キャンバスを追加**を押します。参照データがコレクションのメディアフォルダに
   コピーされ、そこからスマートフォンへ同期されます。
3. 復習中は、キャンバス横の ✓ ボタンで照合のオン・オフを切り替えられます。

一画ごとに分かること:

| | |
|---|---|
| 赤い筆画 | 誤った筆画、または長さが明らかに違う筆画 |
| 橙色の筆画 | 筆画自体は正しいが、筆順が違うか方向が逆 |
| 破線の輪郭 | その筆画が本来あるべき位置 |
| キャンバス下の一行 | 判定結果 — `正解 — 全13画`、`13画中9画が正しい · 4画目: 筆順が違います`、`1画不足` |

フィールドに1文字ではなく単語が入っている場合は、1文字につき1つキャンバスが
横に並び、それぞれが自分の文字と照合されます（図書館なら3つ）。角括弧内の
ふりがなは無視されるので、漢字[かんじ] でもキャンバスは5つではなく2つです。

デフォルトでは一画書き終えるたびに判定します。最後まで書いてから判定させたい
場合は `check_mode` を `"manual"` にし、書き終えてから**判定**を押してください。
どちらの場合も、裏面には表面で書いた字の判定結果がまとめて表示されます。

フィールドを選ぶまで照合は無効で、フィールドのないテンプレートでは関連ボタンも
表示されません。描くだけの使い方には何の影響もありません。

参照データは [KanjiVG](https://kanjivg.tagaini.net) に基づき、常用漢字・人名用
漢字・かな、およびそれ以外の多くの文字を含む6763文字に対応しています。対応外の
文字（ハングル、ラテン文字など）では参照データがない旨を表示するだけで、描画は
そのまま使えます。

照合で分かること・分からないことは [`config.md`](config.md) を参照してください。

## 設定

**ツール → アドオン** で *Kanji Drawing Canvas* を選択し、**設定**をクリックします。

| キー | デフォルト | 説明 |
|------|-----------|------|
| `canvas_size` | `300` | キャンバスの一辺の長さ（ピクセル） |
| `grid_type` | `"tian"` | `"tian"`（田）、`"mi"`（米）、または `"none"` |
| `stroke_width` | `3` | ブラシの太さ（ピクセル） |
| `stroke_color` | `"#1a1a1a"` | 筆跡の色（CSS カラー値） |
| `grid_color` | `"#cccccc"` | ガイド線の色 |
| `background_color` | `"#ffffff"` | キャンバスの背景色 |
| `persist_drawing` | `true` | 裏面に移ったときに筆跡を残すか |
| `restore_after_undo` | `true` | 同じ問題が再表示されたときに筆跡を復元するか |
| `keep_window_seconds` | `90` | その復元が有効な時間 |
| `check_strokes` | `false` | 筆画の照合を最初からオンにするか |
| `check_mode` | `"live"` | `"live"`（一画ごとに判定）または `"manual"`（押したときに判定） |
| `check_tolerance` | `1.0` | 照合の寛容さ。大きくするとより雑な字でも正解になる |

設定を変更した後は、対象テンプレートでキャンバスを**削除してから再追加**することで
新しい設定が反映されます。

---

## 仕組み

アドオンは、選択したノートタイプの*表面*テンプレートの末尾に、特殊なマーカーコメント
で囲まれた小さな自己完結型の `<div>` + `<script>` ブロックを追記します。
新しいフィールドは作成されず、カードデータも変更されません。キャンバスの状態は
一時的なもので、新しいカードごと・カードをめくるたびにリセットされます。
まるで物理的な練習用紙のように使えます。
